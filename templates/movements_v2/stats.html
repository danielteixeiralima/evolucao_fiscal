Sobre o Sistema V2

O Sistema V2 utiliza uma estrutura de banco de dados normalizada, onde:

  • Cada entidade (Empresa, Filial, Centro de Custo, etc.) tem sua própria tabela
  • Relacionamentos são feitos através de chaves estrangeiras (Foreign Keys)
  • Não há campos JSON - todos os dados são estruturados
  • Queries são mais eficientes e o código é mais limpo
Como Importar Mais Dados

Execute o comando abaixo no terminal para importar mais movimentos:

python import_v2.py --inicio 2025-08-01 --fim 2025-11-01 --empresa 4 --filial 17

Ajuste as datas, empresa e filial conforme necessário
